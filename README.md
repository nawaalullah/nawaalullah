## 🚀 Proyek

<details open>
<summary><b>BA Sewa Lahan</b>: Sistem Berita Acara pengukuran sewa lahan</summary>
<br/>

Aplikasi web untuk menyusun, mengekspor, dan mengarsipkan Berita Acara pengukuran sewa lahan di lingkungan Telkom Property (Area Bandung).

- 📝 Formulir 6 langkah dengan draft tersimpan otomatis
- ✍️ Tanda tangan digital untuk 2 sampai 5 penandatangan
- 🗺️ Editor denah interaktif dan pemilihan lokasi di peta
- 📄 Export ke Word dan PDF dengan tata letak sama seperti pratinjau
- 🗂️ Arsip, riwayat pemakaian objek sewa, dan log aktivitas
